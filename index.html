CORE GAMEPLAY

轮回三件套

三个系统一条线串起来玩，构成这个模组的主循环。

轮回者

被选中的单位 · 一阶 ~ 十阶

  • 每隔 30 年（可调 1~100）生成一只挑战骷髅，属性 1:1 复刻 × 档位系数，5 年内打死即完成。
  • 完成奖励永久增加 伤害 / 生命 / 攻速 / 移速 / 寿命 / 防御值 / 免伤 / 破免伤 与轮回币，加成随阶数翻倍。
  • 击杀任何生物都掉 轮回币与经验；击杀轮回者还能收割对方一半轮回消耗、并按比例掠夺其数值。

轮回空间

轮回者的复活点

  • 死亡时若轮回币够 「轮回消耗」（默认 10 枚）就扣币记账、开始倒计时；不够就正常死亡。
  • 到点（默认 20 年）在原死亡位置复活：名字 / 性别 / 种族 / 氏族 / 收藏 / 全部特质 / 属性 / 经验 / 轮回币全保留，连别的模组写在他身上的境界、修为、气运也一起保留。
  • 负面特质全部清除、年龄回到 18 岁；也可以点「立即轮回」马上复活。

轮回商店

你自己上架、自己定价

  • 点空白格「添加」→ 选特质 → 填价格 → 选品质；第一次打开时物品页已铺好 7 枚魂环。
  • 轮回者被记入轮回空间的那一刻自动消费一次：只买 1 件，买得起里品质最高的那件，复活时一起穿上。
  • 互斥组只留最高档（魂环链条、写轮眼链条），被顶掉的那件按售价退还轮回币。

CONTENT LIBRARY

内容图鉴

23 个内容分在四个页签里，每一个都能在「自定义内容数据」里逐项改数字，改完立即生效。

六道轮回眼 紫

传说中六道仙人的眼睛：攻击命中即天降双陨石（第二颗 3 倍），全属性大幅提升、可无视地形。

永恒万花筒写轮眼 蓝

攻击 / 被攻击时自动开启「须佐能乎」，并大幅提升生命、伤害、移速、攻速与暴击率。

三勾玉轮回眼 绿

宇智波一族的血脉：生命 / 伤害 / 移速 / 攻速 / 暴击率全面提升，与更高档的眼睛互斥。

噬体 红

击杀成长：每次击杀叠加属性、掠夺目标总属性、吞噬其能力；累计击杀还会解锁免伤、无视地形、攻击连锁与免疫负面。

真理之书 金

智力 +100 且 +100%；攻击智力低于自己者造成 21 亿物理伤害，无视对方的免伤与防御值。

死亡笔记 紫

攻击改为施加「死亡标记」；每 1 游戏年点名敌方阵营击杀数最高的 5 位，每人 9 亿物理伤害。

无限手套 紫

伤害 / 生命 +900000000、防御值 +9000000、免伤与破免伤 +50%；血量过低时爆发，对全图一半敌人造成巨额物理伤害。

死亡变强系统 金

受到致命伤时原地复活：修为 / 特质 / 氏族 / 阵营关系全部保留，年龄回 18 岁；每次复活永久叠加属性。

百万年魂环 红

千万年魂环 金

六道祭品 紫

杀满 6 人，把这 6 人的生命/伤害/移速/攻速总和 ×6 并入自身；之后每杀 1 人持续延长，期间额外免伤、免疫负面、可飞行。

须佐能乎 蓝

伤害 / 生命 +100%、防御值 +1000、免伤与破免伤 +20%、攻击范围 +20，可跨越地形；由万花筒在战斗中自动开启。

无限闪避 绿

原版「格挡」「闪避」的冷却变为 0，可以无限使用；获得时自动补上这两个原版特质。

疯狂 红

智力永久锁定为 0，见谁打谁、无法建国；复活与读档后依旧保留。

永恒之火 金

每秒燃烧生命上限的 40%，无视一切护持与免伤。

无法攻击 金

从源头掐断一切攻击与施法（含弹道、灵技、神通、法则），登仙等高境界同样生效。

时间冻结 金

真·时间停止：完全停止 AI 与移动，烈焰与登仙都无法解除。

死亡标记 紫

每隔一段时间承受 21 亿物理伤害（受赋予者破免伤加成），无法清除直到该生物死亡。

SYSTEMS

神力与系统

游戏底部神力栏「扎克」页就是入口，另外还有修改器与信息面板。

最高存在配置

模组设置页：观察者生成与全图打击、轮回者获得率、生物转化开关，以及骷髅生成间隔、轮回复活年数两个滑条。

抹除存在 / 无敌橡皮

按画笔范围彻底抹除任何单位：连复活与其它模组的存档副本一起清干净。无敌橡皮是原版橡皮擦的满血致死，只是这一记不吃免伤与防御值。

灭绝书

点击生物类型即可让它灭绝（立刻抹除现存者、此后不再出现）；再点一下恢复。

轮回排行榜

当前存档里全部活着的轮回者排名（可按轮回币 / 品阶排序），点一条就跳到那个单位。

观察者

同一世界唯一、无法被任何方式杀死（含纯移除与强杀通道）、不会被选为目标；攻击命中即抹除目标及其同类同阵营。

扎克修改器

给人授予 / 删除 体质 · 物品 · 技能 · 状态；右上角「自定义内容数据」可改里面出现的每一个数字，改完立刻生效、不用重启。

轮回者信息面板

选中单位后，原版人物面板右侧自动出现：阶数、任务进度、轮回币、属性加成与内容清单，轮回币还能直接点着改。

🧬

生物系统

昆虫生成动物、动物生成人种的开关与概率（默认 20%，可调），让世界自己演化出人种与王国。

QUICK START

四步开一局

  1. 1

    打开配置

    神力栏「扎克」→ 最高存在配置 → 打开「能否获得轮回者特质」（默认关闭，获得率默认 1%）。

  2. 2

    造一个轮回者

    等新单位诞生时判定命中，或直接用「扎克修改器」手动给某个单位加上轮回者特质。

  3. 3

    等它接任务

    每 30 年（可调）刷出一只挑战骷髅，5 年内打死就算完成 —— 属性与轮回币一起涨，经验攒够自动升阶。

  4. 4

    死了别慌

    打开「轮回空间」等倒计时，或直接点「立即轮回」；轮回者回来时等级与家当全都在。

⚠ 使用前请看

本 Mod 仅供娱乐，严重破坏平衡；「观察者」与「抹除存在」会对存档造成不可逆影响， 使用前请务必先备份存档。建议新开存档体验。
