CORE GAMEPLAY

轮回三件套

三个系统一条线串起来玩，构成这个模组的主循环。

轮回者

被选中的单位 · 一阶 ~ 十阶

  • 每隔 10 年（可调 1~100）接一次任务：默认直接发奖；打开「生成骷髅」则改成生成一只挑战骷髅，属性 1:1 复刻 × 档位系数，5 年内打死即完成。
  • 完成奖励永久增加 伤害 / 生命 / 攻速 / 移速 / 寿命 / 防御值 / 免伤 / 破免伤 与轮回币，全部按阶数加成放大（一阶 ×1 → 十阶 ×50000）。
  • 击杀任何生物都掉 轮回币与经验；击杀轮回者还能收割对方一半轮回消耗、并按比例掠夺其数值。

轮回空间

轮回者的复活点

  • 死亡时若轮回币够 「轮回消耗」（默认 10 枚）就扣币记账、开始倒计时；不够就正常死亡。
  • 到点（默认 20 年）在原死亡位置复活：名字 / 性别 / 种族 / 氏族 / 收藏 / 全部特质 / 属性 / 经验 / 轮回币全保留，连别的模组写在他身上的境界、修为、气运也一起保留。
  • 负面特质全部清除、年龄回到 18 岁；也可以点「立即轮回」马上复活。

轮回商店

你自己上架、自己定价

  • 点空白格「添加」→ 选特质 → 填价格 → 选品质；第一次打开时已按建议价铺好 25 件本模组内容（原版特质那一组默认不铺）。
  • 轮回者被记入轮回空间的那一刻自动消费一次：只买 1 件，买得起里品质最高的那件，复活时一起穿上。
  • 互斥组只留最高档（魂环链条、写轮眼链条），被顶掉的那件按售价退还轮回币。
  • 「自定义数值」里还能给商品改名：改完商店、特质栏、提示框全都跟着变。

属性判定 · 免伤 / 破免伤 / 防御值 / 闪避率

本模组新增的四个通用属性。任何来源的伤害 —— 原版攻击、其它模组的技能直伤、本模组的物品与状态 —— 都按同一口径结算，顺序是：先掷闪避 → 再算百分比免伤 → 最后减防御值，残伤 ≤ 0 即 0 伤害。

🛡️

免伤

百分比减伤，无上限（超过 100% 即完全免伤）。可被对方的「破免伤」按百分点抵消： 对方免伤 100% − 你破免伤 10% → 他实际只剩 90%。对原版 getHit、其它模组直写血量、 鬼谷修仙的中心伤害入口统一生效。

🗡️

破免伤

既是攻击属性，也是本模组的「穿透」键（常开，没有开关）。按百分点「减法」吃掉对方的减免： 本模组免伤、鬼谷境界压制（99.99% − 破免伤）、凡人每差 1 境的减伤、玄门 0.1^境界差。 溢出伤害击穿：超出当前生命的伤害会直接扣对方的「天地之力」（鬼谷护体/保命资源），两者都空即击杀。

① 按比例破防御值：本模组防御值 ×（1 − 破免伤%）；原版护甲同样按比例破 （护甲 85 + 破免伤 50% ⇒ 只算 42.5% 的减伤）。

② 穿透别家模组的减伤：凡是挂在 Actor.getHit 上的守方减伤都会被按实测折减系数还原 —— 例如斩神录的境界压制（差 ≥3 境 ×0.02、人类天花板以上每高一境 ×0.5）、西幻 / 龙族等减伤。 这一层不认模组名字，所以以后新装的模组也自动生效。

③ 真伤强制：把「免伤与防御值各自算完、再减去破免伤」之后的那份伤害当真伤打出去 —— 不会被别家继续折、不会被免死层锁血 / 回满、也不吃护盾；打完血量归零就强制走死亡判定 （不再等原版每拍那次检查，开着界面也不会出现「0 血站着不死」）。
★ 死亡仍然走各家的复活机制：本模组的死亡变强 / 不死图腾 / 轮回空间，以及别的模组的复活，照旧生效（可复活）。

以上 ①②③ 只在攻击者破免伤 > 0 时触发；破免伤 0% 时行为与老版本完全一致。 观察者不受影响（那是本模组的「上帝单位」，有自己的免疫通道）。

🧱

防御值

固定抵消伤害，不足抵消时伤害为 0（不保底 1 点）：
对方 200 伤害 − 你 100 防御 → 只受 100；对方 10 伤害 − 你 1000 防御 → 0 伤害。

💨

闪避率

实际闪避率 = 移速项 + 自身闪避率，封顶 0~100%： 移速项 = 自身移速 ÷ 对方移速 × 100 − 100。
自身移速 200 / 对方 100 → 100%；自身 150 / 对方 100 → 50%； 自身 100 / 对方 200 → −50%，此时若自身闪避率 80%（缘一的体质）则 −50% + 80% = 30% （负值不先归零，先加自身闪避率再封顶）。
掷中即整段无视本次伤害连同它的附带效果（赫刀之伤 / 死亡标记 / 死亡笔记点名 / 无限手套爆发都能闪）； 状态跳伤按「施加者移速」算，玩家直接施加的按 1000 移速。
不可被闪避：真理之书碾压、永恒之火、观察者抹除、抹除存在 / 无敌橡皮。

  • ① 表里都是建议价 —— 商店里可以逐件改；改的只是那一件的售价，不影响别的商品。
  • ② 定价口径 = 魂环牌价（1 币 ≈ 六维各 +1）+ 机制溢价：七枚魂环的售价就等于它的年限数值 （十年环 10 币 …… 百万年环 1000 万币、千万年环 1 亿币），其余内容按它带来的机制强度在牌价之上加价。
  • ③ 品质 = 价格档（本模组内容与原版特质同一把尺子）：白 <100 ｜ 黄 100~999 ｜ 绿 1,000~9,999 ｜ 蓝 1万~9.99万 ｜ 紫 10万~99.9万 ｜ 红 100万~999万 ｜ 金 ≥1000万。想调品质就调价 —— 模组每次启动都会按当前价格把货架的品质校准一遍（商店格子、修改器格子、游戏特质栏三处同步）。
  • ④ 不上架的有三类：原版里的负面 / 控制类特质；游戏里「不可手动赋予」的 （三个 desire_* 欲求 + 神迹）；以及刻意排除的「和睦」（永不主动攻击）。 本模组那 6 个状态（疯狂 / 永恒之火 / 无法攻击 / 停止 / 死亡标记 / 赫刀之伤）同理也不上架。
  • ⑤ 2026-09-19 按赚币曲线重定价：有了上面的「升阶耗时表」就能反推每个阶段手上大概有多少币， 于是把 ≤10 万的商品全部保持不动（一~五阶的消费区间）、≥10 万的整体 ×10， 顶级「死亡变强系统」定到 10 亿 —— 排成「六阶 78万 → 七阶 728万 → 八阶 6728万 → 九阶 6.17亿 → 十阶 56亿」逐级买得起的阶梯。售价上限同时抬到 100 亿 （所以「金」现在是一整段：1000万 ~ 100亿）。老存档会自动重定价一次：只改还是默认价的商品， 你手改过价的一律不动。

配置页新增的两个开关

  • 「商店·模组特质自动上架」（默认开）与「商店·原版特质自动上架」（默认关）， 分别把上面那 25 件与 58 件自动铺进商店，不用一件件手动加。
  • 改完立刻生效，不用重启游戏。
  • 关闭会把对应那一组商品全部下架；重新打开则把缺的补齐。
  • 原版那一组默认关：老存档货架上残留的原版特质会在下一次启动时被自动撤掉（只撤一次， 不算「你删过」——以后你把开关打开，它们照常按表回来）。
  • 下架时会先还原被改过的品质 / 名字 / 描述，不留改动痕迹；你自己手动上架的其它特质不受影响。

    看谁最强

    右上角切「顺序：低→高 / 高→低」，搜索框里打名字或种族缩小范围；点一行就跳到它的原版人物面板。

  1. 1

    打开配置

    神力栏「主神空间」→ 最高存在配置 → 打开「能否获得轮回者特质」（默认关闭，获得率默认 1%）。

    死了别慌

    打开「轮回空间」等倒计时，或直接点「立即轮回」；轮回者回来时等级与家当全都在。

EDITABLE STATS

可修改属性的模组

轮回商店有两条改到别的模组身上的路：
① ＋添加属性 —— 轮回商店 → 选一件商品 →「自定义数值」→ 最下面那行「＋ 添加属性」， 列出的是游戏属性库 base_stats_library 里的全部属性（原版 + 本模组 + 其它模组注册的） 加上其它模组写在单位 Actor.data 上的「数据键」， 挑一个填数字就行，点「添加」立刻写进这件商品、并立刻对全场持有者生效。
② 其它模组数值 —— 轮回商店右上角「自定义内容数据」左边那个按钮，读的是别的模组自己的 NeoModLoader 配置文件 mods_config\<模组GUID>.config：数值项点行改数字点保存、开关项点一下即切换。 ★ 这一页改的是它们启动时读一次的设置，要重启游戏才生效（且不按它自己滑条的上限夹取， 例如斗破「修炼倍率」滑条上限是 3，这里能改成 5）。

2026-09-19 起「认模组」是通用的：不再只认手写白名单里的那几个 —— 模组会拿每个已装模组自己的名字 （文件夹名 / mod.json 的 name、GUID / 它目录下的 dll 名）去比属性 id 与数据键， 只要 id 里含那个模组的名字就认它（xianni_* → 仙逆、qol.* → QoL）； 扫源码也改成每个模组保底配额（原来先到先得，后面的模组会一条都读不到）。 所以下面这 21 个联动模组 + 本模组，只要你装了，它的数值就能在这里改到 —— 认不出归属的也照样列（会标「其它模组」，把「隐藏数值」打开就能看到）。

下面每个模组一张卡：点卡片看详情（能改什么 / 改了有什么用 / 具体怎么点）。 有 NML 配置表或源码可核对的模组，键名与数值逐个对照过；本机没装的模组会明确标 「未逐条核对」，只写它的数值存在哪一类，具体键名以你游戏里「＋ 添加属性」页实际列出的为准。
